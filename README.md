# AI Capital

**AI as a guide for the thinking human.**

Part of the [12 Cities](https://github.com/abduljaleel) venture ecosystem.

## What it does

AI Capital is a structured workspace for high-stakes decisions. Not a chatbot — a decision companion that helps knowledge workers through scenario analysis, evidence gathering, frameworks, and decision journaling.

### Core Features

- **Decision Workspace** — Structured space for each decision with context, type classification, and status tracking
- **Scenario Comparison** — Side-by-side analysis of 2-4 scenarios with assumptions, projected outcomes, and probability estimates
- **Evidence Board** — Collect and organize evidence (documents, URLs, notes) with relevance scoring and sentiment tagging
- **Decision Frameworks** — Apply SWOT, Weighted Scoring Matrix, Pre-Mortem, Pros/Cons, and other structured frameworks
- **Decision Journal** — Personal log tracking rationale, confidence levels, and outcome reviews across all decisions

## Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** Tailwind CSS v4 + shadcn/ui
- **Auth & Database:** Supabase (Auth, Postgres, RLS)
- **Deployment:** Vercel

## Getting Started

```bash
npm install
cp .env.local.example .env.local
# Add your Supabase URL and anon key
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
